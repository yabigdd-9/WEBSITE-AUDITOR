# Archived audit implementations and command launchers

Exact source copies of twelve frozen-baseline implementations, stored as .txt so
they are not executable entrypoints. The preservation receipt binds each copy
to its original hash and revision.

The candidate root wrappers retain the already-supported command-line translator
and canonical pipeline. Their former library-only functions are retired from
the active root files; no full library migration parity is claimed. Import
callers and useful older features require acceptance before promotion.

The website_auditor extension package remains in place. It is distinct from
these root scripts and serves existing reporting, connectors and policy users.

wa.py retains its legacy workflow in the candidate with command/status fixes;
advanced_audit.py passes its final fetched URL to shared image/technology/UX adapters.
Its DNS/fetch paths remain pending acceptance. The image plugin's
original arithmetic and counters are preserved here for migration review.
Their archives preserve the baseline for review, rather than retiring those
two active paths or proving their feature parity.

The canonical, typed, plugin and extension technology implementations are also
preserved here. Their candidate APIs share one passive interpreter/catalog.
No numeric confidence calibration or confirmed software installation is claimed.

The original page checks, canonical pipeline and blanket UX plugin are also
preserved. Their candidate UX paths share a static interpreter with explicit
unresolved states; no consent transaction or legal compliance is verified.
